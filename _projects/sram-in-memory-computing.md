## Overview

**Design and Simulation of a Training-Aware SRAM-Based In-Memory Macro for Tsetlin Automata State Updates.** This research investigates circuit-level architectures and mechanisms for efficient state updates in SRAM-based computing systems.

## Research Motivation

Memory-centric computation offers a way to reduce data movement during learning. This investigation focuses on how SRAM-based hardware can support the state updates used by Tsetlin Automata while keeping circuit complexity and energy requirements in view.

## Architecture

The architectural focus is a training-aware SRAM-based in-memory macro supporting Tsetlin Automata state updates. Circuit schematics and implementation details are not publicly available.

## Design Methodology

The work centres on circuit-level design and simulation of memory and state-update mechanisms, examining how learning operations map to SRAM-based circuitry.
